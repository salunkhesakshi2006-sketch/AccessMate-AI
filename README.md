# AccessMate — AI Accessibility Assistant

A simple, responsive, accessibility-first web app for the project topic **AI Accessibility Assistant for People with Disabilities**.

## Features
- Interactive navigation bar and mobile menu
- Chat interface with quick-help prompts
- Optional voice input (browser Web Speech API support required)
- Read replies aloud using text-to-speech
- Font-size controls and high-contrast theme toggle
- Keyboard-friendly controls, visible focus styles, and ARIA labels
- Local demo responses work without an API key
- Optional OpenAI Responses API integration

## Run locally
1. Install Python 3.10+.
2. Extract the ZIP and open a terminal in this folder.
3. Create/activate a virtual environment (optional but recommended).
4. Install packages:
   ```bash
   pip install -r requirements.txt
   ```
5. Start the app:
   ```bash
   python app.py
   ```
6. Open `http://127.0.0.1:5000` in your browser.

## Enable AI replies (optional)
Set an OpenAI API key as an environment variable before starting the app.

**Windows PowerShell**
```powershell
$env:OPENAI_API_KEY="your-api-key"
python app.py
```

**macOS/Linux**
```bash
export OPENAI_API_KEY="your-api-key"
python app.py
```

You can optionally set `OPENAI_MODEL` (default: `gpt-4.1-mini`). Never put API keys in frontend JavaScript or commit them to source control.

Without a key, the app uses simple local demo responses. These are not generated by an AI model.

## Important
This is a student project starter, not a medical or emergency service. Accessibility options and menu names vary by device and operating-system version. Test with keyboard-only navigation and actual assistive technologies before presenting or deploying.
